# AI写作助手（aiWrite）

> 一款本地运行的 AI 小说写作助手，支持多 LLM 接入、章节管理、智能续写、导入导出等功能。

## 项目简介

AI写作助手是一款面向网络小说创作者的桌面/移动端应用，基于 Capacitor 8 + 原生 JavaScript 构建。所有数据存储在本地 SQLite 数据库中，不依赖云端服务，保障创作者的隐私与数据安全。

### 核心功能

- **多 LLM 接入**：支持 DeepSeek、OpenAI、讯飞星火、智谱 GLM、Kimi、通义千问、腾讯混元、七猫、番茄等多家 AI 服务商
- **章节管理**：创建、编辑、删除、排序章节，支持分卷管理
- **智能续写**：基于上下文自动生成后续内容，支持流式输出
- **人物管理**：创建角色卡片，关联出场章节，AI 生成时自动引用
- **世界观设定**：维护故事背景、力量体系等设定
- **导入导出**：支持 TXT / DOCX 格式导入导出
- **备份恢复**：全量备份与恢复，支持加密存储
- **回收站**：软删除机制，误删可恢复
- **草稿守卫**：自动保存编辑中的内容，防止意外丢失

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | 原生 JavaScript（ES6+，无框架依赖） |
| 移动端壳 | Capacitor 8（Android） |
| 数据库 | SQLite（本地存储） |
| 加密 | AES-256-GCM（Android KeyStore） |
| 构建工具 | PowerShell + Gradle |

```bash
# 构建 Android
.\build.ps1
```
